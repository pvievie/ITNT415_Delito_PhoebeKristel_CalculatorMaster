## Project Description
A menu-driven Python calculator developed using a Git and GitHub feature-branch workflow. The final version integrates all core mathematical operations into a single application.

## Branch Structure
- main: Contains the final integrated application.
- addition_Delito: Implements the addition operation with validation.
- subtraction_Delito: Implements the subtraction operation with validation.
- multiplication_Delito: Implements the multiplication operation with validation.
- division_Delito: Implements the division operation with validation and zero-division handling.

## Program Features
- Menu-driven interface
- Continuous execution until the exit option is selected
- Proper modular function definitions
- Error handling for invalid (non-numeric) entries on all operations
- Division-by-zero handling
